# AIML-task-PS1
team: CodeVerse

ps 01 : AI-Driven Hyper-Personalisation & Churn
Intelligence Platform
Large enterprises such as insurance providers, banks, and subscription-based platforms
manage millions of customers using generic persona-based segmentation (often 1000+
static personas). While scalable, this approach fails to capture individual-level behavior,
intent, sentiment, and evolving preferences, leading to:
Low conversion rates
Poor upselling effectiveness
High customer churn
Reduced customer lifetime value (CLV)
Organizations lack an AI-first, individual-centric system that can predict customer intent,
personalize offerings in real time, and proactively prevent churn.
Your challenge is to design and build an AI-powered platform that unifies personalisation,
purchase propensity prediction, and churn intelligence into a single, adaptive system
